# Bookify

A modern book recommendation system that helps users discover books and research papers based on their interests. The application uses AI to provide personalized recommendations and integrates with various sources including Internet Archive and Semantic Scholar.

## Features

- AI-powered book and research paper recommendations
- Integration with Internet Archive for classic books and papers
- Integration with Semantic Scholar for recent research papers
- Modern chat interface for natural interaction
- Real-time book and paper previews
- Direct links to read or purchase recommended items

## Setup

1. Clone the repository
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Set up environment variables in `.env` file
4. Run the application:
   ```bash
   python app.py
   ```

## Technologies Used

- Python/Flask
- HTML/CSS/JavaScript
- OpenAI API
- Internet Archive API
- Semantic Scholar API
